# 有限取名字庫

`limited-v1.json`（limited-zh-TW-v1）只收既有 `lin-baby-name-checks.json` 核對的 12 字：林、峻、城、峰、垣、宥、鋒、銳、錚、錫、鈺、澄。林僅作固定姓；宥有筆畫讀音但尚無試行五行分類，不進候選池。宏、志僅供避音，不作取名字與姓氏筆畫來源。

筆畫與國語讀音沿用研究欄位及其逐字漢典網址。2026-11-03 補核宏、志讀音及澄的國語多音（ㄔㄥˊ、ㄉㄥˋ）；錫採國語辭典ㄒㄧˊ，不採頁首普通話讀音。JSON 保留來源及研究註記；短字義是本專案自行撰寫，未複製字典全文或圖片。僅使用少量可核對事實，不抓取整站，字典內容未取得重新散布整站內容的授權。

trialElement 是研究模型依部首及字義作的未驗證分類，不是字典認證或 OpenFate 規則。五格吉數與相鄰三才不相剋沿用 `lin-baby-naming-arithmetic.json` 試行算例，吉數清單凍結在此版；天格不過濾吉數。取名採單姓、雙字名，未知姓筆畫／避音／指定字會停止，零候選不放寬限制。程式保守排除全名任兩字重字或任一已知國語音調相同；同音包含每字所有本字庫已知國語讀音，不涵蓋方言與未收讀音。字庫範圍有限，結果不能代表全字庫最優。

## v2 研究資料

`limited-v2.json`（curated-zh-TW-v2／naming-pools-trial-v2）保留原12字並新增10字，共22字。每字含字面義、祝願引申、風格、注意事項及音義／康熙筆畫／命名分類來源；[逐字來源、分類政策與限制](sources-v2.md)為本版研究依據。

v2採固定外部民俗命名分類，與v1內部模型不同：峻由土改金、峰由土改水、宥補上土。這是版本化試行政策，不表示已驗證命名學效力。v1檔案保留，不更動既有歷史版本。林姓、避宏志同音同調的兩組4×4研究證據在`tmp/report-redesign/task1-pools.json`；這些池不是產品硬編碼，也不保證其他姓氏／必用字仍可成立。產品載入與版本失效處理由生成核心負責，本檔新增不代表程式已接線完成。
