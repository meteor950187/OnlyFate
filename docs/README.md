# 文件收錄與治理

本目錄保存產品約定、開發慣例、研究入口及有必要持續維護的詳細脈絡。未決事項必須標明狀態，不得寫成已實作能力。

文件的權威範圍、讀取時機、生命週期與關聯由 [map.md](map.md) 管理；本頁不重複維護文件清單或決策索引。

Agent 穩定規則放根目錄 AGENTS.md／CLAUDE.md；操作入口放對應 README。原始工具輸出與產出物保留其自身檔案，文件以連結引用，不整份複製。不要收錄密鑰、真實客戶個資、冗長聊天逐字稿或未驗證的操作指令。

文件新增、移動、刪除，或權威範圍、讀取時機、生命週期、關聯改變時更新 Map；一般內容修訂不用同步變更 Map。
