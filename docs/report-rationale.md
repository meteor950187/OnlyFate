# 報告閱讀節奏與命名依據補強

2026-11-03。使用者要求前段更寬敞，且能看懂八字、選字方向、筆畫配置與每字入選的關係。沿用已授權的一般設計自決；不改命理方法，不另加模型呼叫。

採用：首頁保留結果優先並增加卡片留白；其後獨立說明出生判讀，再於每組配字後以完整頁幅解釋五格公式、採用條件及三才。逐字卡加上實算筆畫與試行字五行，連到字池條件。只放大字體不能補足理由；事後請模型補編理由會失去來源，因此不採用。

資料：ReportData新增命名依據快照，取自與選名相同的Step3 run，驗證命盤引用與選字五行一致；保留summary/direction/evidence/limitations。模型短文context維持原本最小範圍。版型升版，舊報告保留且明確提示過期，不覆寫既有產物。

林姓Demo：補齊既有研究的條件式扶抑思路、午月/申根/壬水反證，仍標示土金尚未定案；不能稱為已驗證喜用。三才是姓名筆畫的第二層篩選，不是直接把八字換成三個字五行，也不宣稱9+16或13+10是唯一最佳組合。

步驟：先新增來源/展示測試→接入判讀快照與校驗→改版面及Demo可追溯說明→跑全套→實際HTML/PDF逐頁驗收→同步發行入口。

驗證：錯run/錯五行/缺依據不得組報告；正常與Demo均保存同契約；五格算式取實值、同組所有字位置筆畫一致；無腳本、HTML編碼及既有失效/取消保護不變。長文字自然分頁，首頁與方案推薦區增加間距，不擠壓後段。

依據查核（2026-11-03）：[OpenFate取用方法](https://wiki.openfate.ai/zh-hant/bazi/useful-gods-climate)、[五格公式](https://shunshi.ai/zh-tw/wiki/naming/wuge/wuge_intro)、[數理分類表](https://d0works.com/stroksIntro.php)。採用的四格分類及相鄰不相剋仍是本專案試行政策，不冒充來源網站完整方法。歷史分歧見既有案例試走與字庫來源。

## 家長閱讀定位修正

交付讀者是沒有命理背景的家長。報告只回答：命盤的主要特點、取名方向、每組名字寄託與如何選字。計算公式、檢查用途、方法糾錯、完整反證留在系統紀錄，不逐條印出。重要未定案事項以短句誠實保留。Step3 的 summary/direction/limitations 指令同步採家長語言，evidence 繼續保存可稽核細節；不靠字串刪除把內部說明假裝改寫成客戶文案。

版型 v5 取消五格算式表及逐字重複的入選條件；組別理由改為白話心意並與字義相連，保留同組搭配操作說明。保持首頁留白。此次只產出 HTML 文字預覽及無視窗測試，不重做 PDF 桌面驗收；v4 PDF 保留為前版。
