# 可執行程式與報告產物

- `app/`：本機發行版，開啟 [OnlyFate.Desktop.exe](app/OnlyFate.Desktop.exe)。須保留整個資料夾；執行依賴與操作見 [開始驗收](../docs/acceptance.md)。
- [已確認的 PDF v11](pdf/onlyfate-naming-report-v11.pdf) 與[新版 HTML 預覽 v12](pdf/onlyfate-naming-report-v12.html)：隔離林姓示範，兩者內容、標題層級與主推標示一致。HTML 採段落導覽、可隨視窗調整的雙欄／單欄字卡；列印仍為已確認的六頁配置。本輪未重做原生 WebView2 列印，背景 Edge 比對改版前後的六頁文字及轉圖結果完全一致。
- `pdf/` 其他樣張：歷史 Mockup 與舊版驗收，保留供比較，不當成目前生成規格。

產物維持試行／虛構示範標示，不代表命理方法或真實模型品質已驗證。內部案件資料及報告收據位於使用者本機資料目錄，不在此資料夾。

歷史成品保留供比較：v6 三頁、v7 五頁、v8 加入推薦前八字分析的六頁版、v9 精簡版、v10 放寬字卡及補足選字說明版。驗收範圍與證據以[驗收紀錄](../docs/acceptance.md)為準。
